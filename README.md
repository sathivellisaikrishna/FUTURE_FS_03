# FB Fitness Unisex Gym Website

## About the Project

This project is a responsive website I built for a real local gym called **FB Fitness (Unisex Gym)** as part of my Full Stack Web Development internship task.

The main idea behind this project was to create a simple but professional website that helps the gym showcase its services, pricing, and contact details in a clear and attractive way.

---

## What I Built

I designed and developed a complete business website that includes:

* Home page with a strong first impression
* About section explaining the gym
* Services offered by the gym
* Membership pricing plans
* Gallery of the gym facility
* Testimonials from members
* Contact section with map, phone, and WhatsApp

---

## Technologies Used

* HTML
* CSS
* JavaScript (Vanilla JS)

I used only basic web technologies without any frameworks to strengthen my fundamentals.

---

## Key Features

* Fully responsive design (works on mobile and desktop)
* Modern dark UI with neon styling
* Smooth scrolling navigation
* Interactive elements like menu toggle and animations
* Google Maps integration
* WhatsApp contact button for quick communication
